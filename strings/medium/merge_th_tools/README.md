## 📝 Description
Given a string `s` and an integer `k`, split the string into equal-sized substrings of length `k`.
For each substring, remove duplicate characters while preserving the order of their first occurrence,
then print the resulting string.

## 📌 Source
- **HackerRank:** https://www.hackerrank.com/challenges/merge-the-tools/problem?isFullScreen=true

## ⏱️ Complexity Analysis
- **Time Complexity:** `O(n)`, where `n` is the length of the input string.
- **Space Complexity:** `O(k)`, where `k` is the integer given by user to split the string
